# Reproducibility

Before held-out runs, checksum and freeze:
- embedding configuration;
- base/query vectors;
- metadata table;
- DiskANN graph;
- exact filtered ground truth;
- query/filter workload;
- search parameters;
- resource profiles.

Record hardware, OS, compiler, DiskANN commit, Python package versions, thread count, warm-up, repetition count, and timeout policy.
